Bring a personal token for a higher API limit.

For public repo discovery, use a fine-grained personal access token with no repository permissions. Requests go directly from this browser to api.github.com.

This draft stores the token in this browser’s local storage. Don’t use it on a shared device or deploy as a public app with a personal token. A production site should use GitHub OAuth or a server-side integration.
